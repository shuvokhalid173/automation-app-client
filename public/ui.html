Web Automation UI

User Manual — Managing business automation files, domains & mailboxes

Welcome to the Web Automation UI for managing your business automation files, domains, and mailboxes. This guide will help you navigate the system and use its features effectively.

1. Dashboard Overview

The Dashboard is the main screen of the application. It provides a comprehensive view of all your processed files and invoices.

  • Global Statistics — At the top, you can see total files, downloaded files, uploaded files, and pending files across all your domains.
  • Filtering — Use the top filter bar to narrow down the files:
    • Select a specific Domain and Mailbox.
    • Filter by a specific Month (e.g., January 2024).
    • The statistics and the file table will automatically update based on your filters.
  • File Table — Displays a list of all your files:
    • View file metadata by clicking the ℹ️ (Info) button.
    • View the actual PDF file directly in the browser by clicking the 👁️ (View) button.
    • If a file hasn’t been uploaded to its final destination yet, you can manually trigger the upload using the ⬆️ (Upload) button.
Button Action
ℹ️ Info Displays metadata about the selected file.
👁️ View Opens the PDF file directly in the browser.
⬆️ Upload Manually triggers the upload to the final destination (only available for pending files).

2. Settings Page

The Settings page allows you to configure the core entities of your automation system: Domains, Mailboxes, and Manual Uploads. Click the “Settings” button (or the gear icon) in the top right corner of the Dashboard to access it.

2.1 Managing Domains

In the Settings sidebar, click on Domains.

  • Add a Domain — Click the “+ Add Domain” button, provide a name and URL, and save.
  • Edit / Delete — Use the “Edit” or “Delete” buttons next to any existing domain to modify or remove it.

2.2 Managing Mailboxes

In the Settings sidebar, click on Mailboxes.

  • Add a Mailbox — Click the “+ Add Mailbox” button. You will need to provide a Name, Email, and link it to an existing Domain using the dropdown.
  • Status — You can mark mailboxes as active or inactive. Only active mailboxes are typically processed by the automation scripts.

2.3 Manual Uploads (eBay & Google Ads)

If you have invoices from eBay or Google Ads that the system couldn’t fetch automatically, you can manually upload them directly into the correct system folders.

  1. In the Settings sidebar, click on Manual upload (eBay) or Manual upload (GoogleAds) depending on the invoice type.
  2. Click Select PDF File and choose the invoice from your local computer.
    Note: Only .pdf files are supported.
  3. Click the Upload File button.
  4. The system will securely transfer the file to the dedicated backend folder (downloads/eBay or downloads/google-ads), appending a timestamp to the filename to ensure existing files are never accidentally overwritten.
  5. A success message will appear once the upload is complete. The automation scripts will then process these files from the folder as usual.

Troubleshooting

“Could not load the PDF”
If you see this error when viewing a file, the file might not exist in the designated local storage path, or it might be corrupted.
Upload Button Disabled
If the upload button in the file table is grayed out, it means the file has already been uploaded to its final destination and no further action is required.
Missing Domains in Dropdown
When creating a mailbox, if the domain dropdown is empty, you must first create a Domain in the Domains tab.
